# markdown-tpsit

## Cos'è?

Questo è un repository personale che contiene gli esercizi del modulo M1, gli appunti del modulo M1 su markdown.

È un progetto scolastico, serve per imparare ad usare Visual Studio Code, Git (CMD) ed infine GitHUb.

## Come si sfoglia

Questo repository comprende gli appunti delle lezioni di laboratorio della materia TPSIT.
Contiene il modulo M1, questo si può leggere aprendo la cartella M1 direttamente da GitHub.

-Istruzioni
1. Clona il repository sulla tua postazione 
    git clone https://github.com/carlottalorenzi/markdown-tpsit.git
2. Apri una cartella per vedere il suo contenuto
    - M1 
    Poi al suo interno
    - file dei compiti
    - 03_codice -> per appunti dati dai professori
    - appunti -> per appunti presi a lezione 
    - docs ->
        - immagini -> immagini che ci sono all'interno del repository
        - file di prova  - file degli esercizi del modulo
3. Clicca sul file che vuoi consultare per vedere il suo contenuto

## Organizzazione del repository
| Cartella o file | Contenuto |
| :--- | :--- |
| M1 | compiti e appunti del modulo 1 |
| 03_codice |  appunti dati dai professori |
| appunti | appunti presi a lezione  | 
| docs | file degli esercizi del modulo | 
| immagini | immagini che ci sono all'interno del repository |
| README.md | questo file |

## Strumenti usati
- GitHub per la cronologia e la pubblicazione del repository
- Git per il controllo di versione e per avere tutto sulla propria postazione
- Visual Studio Code come editor
